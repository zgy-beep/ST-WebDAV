# 架构决策记录（ADR）

记录**为什么这么做**，防止半年后重复讨论同一件事。

**命名**：`NNN-<简短标题>.md`，序号连续递增。

**模板：**

```markdown
# ADR-NNN：<决策标题>

- 状态：草稿 / 已接受 / 已废弃（被 ADR-XXX 取代）
- 日期：YYYY-MM-DD
- 相关：#<issue 编号>

## 背景

<!-- 当时的处境与约束，为什么需要做决策 -->

## 决策

<!-- 选定了什么。用肯定句。 -->

## 备选方案

<!-- 考虑过但没选的方案，以及为什么没选 -->

## 后果

- 正面：
- 负面：
- 需要配套做的事：
```

**什么时候写 ADR：**

- 引入或移除一个依赖
- 改变模块边界或依赖方向
- 改变数据存储格式
- 做出有明显取舍的技术选型
- 推翻既有约定

**什么时候不用写**：日常 bug 修复、小范围重构、纯文档修正。
