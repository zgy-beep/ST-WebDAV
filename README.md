# ☁️ ST-WebDAV (SillyTavern WebDAV 全量备份与还原插件)

> 📦 **流式零内存挤压 · 端到端 AES-256-GCM 加密 · Zip-Slip 深度防御 · 现代 Flat Glass 界面**
> 
> 专为 [SillyTavern (酒馆)](https://github.com/SillyTavern/SillyTavern) 打造的 WebDAV 全量备份、版本历史管理与灾备还原插件。支持将酒馆的配置（`settings.json`、API Key、预设、世界书、主题）或全量资产（角色卡、聊天记录、用户文件）自动无损同步至你的私有云或云盘。

---

## ✨ 核心特性

- ⚡ **零临时落盘 · 零 OOM 流式打包**：基于 Node.js 管道流与 `archiver`，一边扫描压缩、一边通过 HTTP PUT 推送到 WebDAV，常驻内存仅几十 KB，即使面对上 GB 的大型角色卡与长对话历史也不会吃满内存或导致酒馆崩溃。
- 🛡️ **端到端加密保护 (E2EE)**：支持开启 **AES-256-GCM + PBKDF2** 强加密。敏感 API 密钥与私密对话在推离本地前完成加密，在第三方网盘上为完全不可读密文，即便网盘泄露也无惧数据曝光。
- 🚫 **Zip-Slip 漏洞终结者**：在解包还原备份时强制进行绝对路径与归属沙箱校验，彻底杜绝恶意构造的 `../../` 路径穿越逃逸与任意系统文件覆写攻击。
- 🌐 **严格的 SSRF 拦截防御**：WebDAV 连接强制实施协议白名单与云厂商元数据服务（`169.254.169.254` 等）拦截，杜绝内网穿透探测隐患。
- 🔄 **自动安全回滚快照 (Rollback Snapshot)**：在执行远端还原覆写前，服务端会自动在本地打包一份即时回滚快照；若还原异常可无损倒退。
- ⏰ **定时备份与历史自动轮转**：支持配置定时自动备份周期（如每 24 小时）与远端备份保留份数（如保留最新 10 份），超额自动清理远端最旧备份，防止占满网盘空间。
- 🤝 **跨账号跨用户共享备份**：可将任意备份「分享」到共享区，所有能访问该 WebDAV 路径的用户与账号都能看到并一键还原，无需互加好友、无需交换凭据；支持撤回分享，共享区文件互不干扰。
- 🎨 **最新在线 UI Kit（Flat Glass 扁平玻璃设计）**：前端界面采用在线动态加载模式，实时跟随 [`zgy-beep/ui-kit`](https://github.com/zgy-beep/ui-kit) 仓库迭代；本地内置 v2.8.0 离线副本作为兜底；原生适配桌面端居中浮层（880px）与手机端底部抽屉 + 底部导航栏自适应切换。

## 快速安装与使用

### 1. 开启酒馆服务端插件功能

编辑酒馆根目录的 `config.yaml`：

```yaml
enableServerPlugins: true
```

### 2. 部署插件

将本仓库克隆或软链接至酒馆插件目录：

**作为服务端插件与前端扩展（推荐软链接）：**
```bash
# 在 SillyTavern 根目录下执行：
cd plugins
git clone https://github.com/zgy-beep/ST-WebDAV.git st-webdav
cd st-webdav
pnpm install # 或 npm install
```

同时在酒馆前端扩展目录建立软链接（使酒馆识别前端 UI）：
```bash
# Windows (管理员 PowerShell):
New-Item -ItemType SymbolicLink -Path "public/scripts/extensions/third-party/ST-WebDAV" -Target "plugins/st-webdav"

# Linux / macOS:
ln -s ../../../plugins/st-webdav public/scripts/extensions/third-party/ST-WebDAV
```

### 3. 重启 SillyTavern

启动酒馆后：
1. 点击酒馆右上角的 **扩展菜单（魔法棒图标）**；
2. 找到并点击 **「WebDAV 备份」** 按钮；
3. 在弹出的现代化 Flat Glass 面板中前往 **「服务设置」**，填入你的 WebDAV 地址与账号密码，点击「测试连接」验证通过即可！

## 共享备份（跨账号跨用户）

在多用户酒馆或多人共用同一台服务器的场景下，备份常常需要「互相同步」：管理员希望把自己配好的预设分发给所有账号，账号之间也想交换角色卡与设定，而不必互相索要 WebDAV 账号密码。

### 共享区位置

```
<远端备份根目录>/_shared/
```

例如配置根目录为 `SillyTavern_Backups` 时，共享区固定位于 `SillyTavern_Backups/_shared/`。

**该目录不带用户标识** —— 无论是否开启「多用户独立子目录空间隔离」，所有能访问该 WebDAV 路径的用户与账号共用同一片共享空间。

### 使用方式

1. 在「远端历史」标签页中，切换到「我的备份」列表；
2. 点击某个备份卡片上的 **分享** 按钮，即可将其复制到共享区（服务端通过 WebDAV `COPY` 完成，无需下载到本地再上传）；
3. 任意其他用户或账号切换到 **共享备份** 列表，即可看到该备份，点击 **还原此备份** 即可导入自己的酒馆（加密备份需输入解密口令）；
4. 分享者本人可随时 **取消分享**。

### 权限规则

| 操作 | 允许者 |
| :--- | :--- |
| 分享自己的备份 | 任意已登录用户（从自己的目录发起） |
| 查看共享区列表 | 任意已登录用户 |
| 还原共享区备份 | 任意已登录用户 |
| 取消分享 / 删除共享文件 | **仅分享者本人或管理员**；其他用户操作返回 403 |

同名冲突保护：若目标文件名已被**其他用户**分享，再次分享会被拒绝（返回 409「同名备份已由其他用户共享」），避免互相覆盖。

### 安全说明

- 共享区**不受**各用户的历史轮转策略影响 —— 轮转只作用于用户自己的备份目录，不会误删他人分享的文件；
- 共享区文件的元数据索引（`st_shared_meta.json`）使用 per-directory 互斥锁串行化写入，避免多人同时分享时丢失更新；
- 共享区中**不包含**任何账号的本地凭据配置文件（`st_webdav_config.json`），备份包内的凭据文件在打包与还原两侧均被拦截。

## 安全防护与设计规范

1. **凭据脱敏存储**：
   - 配置文件持久化时，密码以保护模式存储（文件权限 `0600`）；前端拉取配置接口一律返回 `********` 掩码，杜绝屏幕录制或网络拦截泄露。
   - **凭据配置文件永不进入备份包**：全量、核心、自定义三种备份模式均排除 `st_webdav_config.json`；还原时同样跳过（大小写不敏感），避免跨用户还原把凭据导入他人目录。
2. **端到端加密**：
   - 加密格式采用 **AES-256-GCM**，v2 头部包含 8 字节 Magic Marker (`STWBDV02`)、4 字节迭代次数、16 字节随机盐 (Salt) 与 12 字节 IV，末尾追加 16 字节 Auth Tag。每次加密均派生完全不同的一次性密钥与向量，密文具备不可延展性（Non-malleability）。
   - KDF 强度为 **PBKDF2-HMAC-SHA256 / 210,000 次**迭代，且使用异步派生（不阻塞事件循环）；历史 v1 格式（`STWBDV01`，100,000 次）备份仍可正常解密还原。
3. **Zip-Slip 零容忍拦截**：
   - 解压每个文件前均强制执行 `path.resolve` 与沙箱根路径比对，严禁跳出当前用户数据根目录。
   - 还原采用**两阶段**流程：先遍历全部条目完成路径与配额校验，通过后才统一写盘，安全拦截时磁盘上不会残留半还原文件。
4. **Zip-Bomb 前置防御**：
   - 配额检查在**实际解压之前**执行（基于 zip 头声明的解压尺寸），超限条目直接拒绝；STORED（不压缩）条目按实际占用计费，防止谎报尺寸绕过。
5. **SSRF 防护**：
   - 协议白名单 + 云厂商元数据服务拦截（覆盖十进制/十六进制/IPv4-mapped IPv6 等变体）；
   - HTTP 重定向逐跳重新校验，跳转目标**必须**重新通过 SSRF 检查；**跨源跳转自动剥离 Authorization 头**，防止 WebDAV 密码被 302 送到第三方主机。
6. **多租户隔离**：
   - 每个账号拥有独立的配置、数据目录与远端子目录；备份与还原对同一账号互斥，避免并发读写产生不一致的备份包。
   - 关闭隔离改为共享目录时，轮转与删除均按文件归属前缀限定，不会误删他人备份。
